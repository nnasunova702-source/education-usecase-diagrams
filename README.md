# Автоматизация работы отеля (Use Case Diagram)
## 👥 Основные действующие лица (Actors)
* **Сотрудник отеля**: инициирует основные бизнес-процессы (бронирование, заселение, работа с претензиями).
* **CRM-система**: автоматизирует проверки и предоставляет подсказки сотруднику.

## 📝 Ключевые сценарии использования
* **Управление бронированием**: создание, редактирование и отмена броней.
* **Работа с профилем гостя**: заполнение данных, автоматическая проверка по «черному списку» и автозаполнение для повторных клиентов.
* **Процесс размещения**: заселение и выселение гостей, прием оплаты.
* **Сервис и лояльность**: обработка претензий, предложение дополнительных услуг (ТИУ) и получение автоматических подсказок по компенсациям или залогам.

## ⚙️ Технические особенности
Диаграмма отображает сложные связи типа «extend» (расширение), показывая, как система реагирует на специфические условия (например, необходимость залога в зависимости от тарифа).
